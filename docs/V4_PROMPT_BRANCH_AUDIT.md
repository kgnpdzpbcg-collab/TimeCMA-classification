# V4 文本分支与跨工况风险审计

> 状态：已完成代码与已保存 checkpoint 的只读核验。本文记录事实、可支持的推断，以及尚不能下结论的部分；不包含模型改动或重新训练。

## 1. 审计对象与可追溯信息

- 模型版本：`Version-4` 的 DE/FE 双传感器、重叠 patch、cross-attention 架构。
- 已核验 checkpoint：`Results/CWRU_TimeCMA_FD/v4_de_fe_overlap_true_cross_attention/best_model.pt`。
- 原始随机文件级测试结果：Accuracy `96.537%`，Macro-F1 `95.648%`。
- 信号输入：`[B, 1024, 2]`（DE、FE）；局部 patch：长度 256、步长 128，共 7 个 token。
- Prompt embedding：`[B, 768, 7, 1]`；缓存由冻结 GPT-2 从每个局部 patch 的英文统计描述生成。

## 2. 文本分支是否参与当前分类决策

### 2.1 反事实测试

保持测试信号不变，只替换其缓存的 prompt embedding：

| 干预 | 评估范围 | 预测标签变化 | Accuracy / Macro-F1 |
| --- | --- | ---: | --- |
| 用健康样本的 prompt 替换 | 全部 1184 个测试窗口 | 0 | 与基线完全一致 |
| 在测试集内随机置乱 prompt | 全部 1184 个测试窗口 | 0 | 与基线完全一致 |
| 用健康 prompt 替换 OR014@2HP 的 prompt | 118 个 outer 窗口 | 0 | 标签完全不变 |

在 OR014@2HP 的 118 个窗口上，健康 prompt 替换造成的平均绝对 logit 改变量为 `0.0119`；换成另一个外圈信号时，该量为 `2.1886`，约为前者的 `184` 倍。

### 2.2 可支持的结论

在**当前 V4 checkpoint 和当前测试分布**上，文本输入对最终预测没有可观察的决策贡献；V4 的分类实际几乎完全依赖波形分支。

不能把这写成“数学上 100% 不使用文本”：替换 prompt 后 logit 有极小但非零的变化，且本审计没有穷举所有人为构造的文本输入。论文中应表述为“在所测反事实干预下，预测对 prompt 不敏感”。

## 3. GPT-2 池化位置

### 3.1 已确认的代码事实

`utils/phm_prompt.py` 的 prompt 句子以 `". "` 结束。实际分词后，最后一个有效 token 是独立的 GPT-2 空格 token（id `220`，显示为 `Ġ`）。代码通过：

```python
pos = encoded["attention_mask"].sum(dim=1).sub(1)
emb = hidden[torch.arange(hidden.size(0)), pos]
```

保存这个最后位置的 hidden state。因此，当前每个 patch 的 embedding 确实取自“末尾空格位置”。

### 3.2 不能直接推出的结论

GPT-2 是因果 Transformer，末尾空格位置的 hidden state 理论上仍可注意到前面的文字和数字。因此，“最后 token 是空格”是一个缺乏语义合理性、应修复的池化设计，但**不能单独证明**此前数字必然被丢失。

要验证其因果影响，必须以新的池化规则重新生成全部缓存并重新训练；只在旧 checkpoint 推理时替换 embedding 会产生训练/推理分布不一致，不能作为改善效果的证据。

## 4. Prompt 数值字段审计

每个 DE/FE patch 都写入 `mean`、`std`、`RMS`、`peak`、`skewness`、`kurtosis`、`crest factor`、`dominant frequency`，共 16 个数值字段。

| 字段问题 | 已确认事实 | 严格解释 |
| --- | --- | --- |
| `std` 与 `RMS` | 代码分别计算中心标准差和 `sqrt(mean(x^2))` | 恒有 `RMS² = std² + mean²`。振动均值接近零时，两者高度冗余，但不是严格恒等。 |
| `mean` | 每个局部 patch 都写入均值 | 其类别区分度和是否为采集卡直流偏置尚未独立验证，不能严谨称为“纯噪声”。 |
| `dominant frequency` | 对去均值后原始 rFFT 的最大幅值 bin 取频率 | 未做包络谱、BPFO/BPFI/BSF 或轴承几何计算，不能声称提取到故障特征频率；强峰可能是共振或其他成分。 |
| 频率分辨率 | `12000 / 256 = 46.875 Hz` | 该分辨率限制了低频、相近故障特征的区分能力。 |

因此，可确认的是“字段存在冗余和物理含义不充分”；“8 个字段全部无效、剩余 8 个全部有效”尚没有足够证据。

## 6. OR014 文件级泛化风险

| 文件 | 所属集合 | DE 标准差 | 外圈判对窗口 / 总窗口 |
| --- | --- | ---: | ---: |
| OR014@0HP | train | 0.099648 | 118 / 118 |
| OR014@1HP | train | 0.093528 | 119 / 119 |
| OR014@2HP | test | 0.096764 | 83 / 118 |
| OR014@3HP | train | 0.094681 | 119 / 119 |

OR014@2HP 的 35 个错误占原随机文件级测试全部 41 个错误的 `85.4%`，是 V4 随机划分高分最重要的薄弱点。

这说明模型对“同一故障尺寸、不同采集文件/负载”的泛化不稳定，也与“记住训练文件特征”的解释相容。但四个文件负载、转速和独立采集记录均不同，不能称为物理上完全相同；仅凭这一组结果也不能证明模型只是在背答案。严格区分两种解释需要文件级跨工况协议，例如 LOLO。

## 7. RevIN 与文本幅值口径

`models/TimeCMA_FD.py` 在模型内对每个样本、每个传感器沿时间维做标准化：

```python
signal = self.normalize(signal.float(), "norm")
```

而 prompt 的统计量来自标准化前的原始波形，两个模态的幅值口径确实不一致。

但是，在当前 V4 中 prompt 替换没有改变测试预测，因此没有证据支持“该口径不一致导致了 OR014@2HP 的错误”。这项问题应在文本分支被修复并证明会参与决策后重新评估。

## 8. 对后续工作的约束

1. 保留 V4 和其缓存作为不可修改的基线，避免改写历史结果。
2. 在修改 prompt 前，先完成严格的 prompt 消融：原始、随机置乱、健康替换、零/常量 prompt，以及仅信号模型；每个条件必须固定 split、seed、训练预算和模型选择规则。
3. 若决定修复文本分支，应使用新缓存目录与新实验版本，重新生成 embedding、重新训练，且保留“末尾空格池化”的 V4 对照。
4. 跨工况结论以四个 LOLO fold 的 Macro-F1 `mean ± sample std` 为主，不把高度相关窗口视为独立重复试验。
